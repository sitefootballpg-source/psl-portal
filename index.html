Google Sheets Automated CMS Setup Guide

Follow these steps to connect your own free Google Sheet as the admin database.

1

Create Google Sheet

Create a new sheet and make sure your first row (header) contains these exact column names:

ID, Round, HomeTeam, AwayTeam, HomeScore, AwayScore, Status, Date, Time, Venue, HomeScorers, AwayScorers, POTM, Summary
2

Publish to Web (CSV)

In Google Sheets, go to File > Share > Publish to web.

Select Web Page -> change to Comma-separated values (.csv) and click Publish.

3

Paste URL in Website

Copy the link provided by Google Sheets, click "Connect Google Sheet" at the top right of this page, and paste your URL.
